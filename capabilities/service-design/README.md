# Service Design

사람이 경험하는 서비스와 이를 제공하는 운영 과정을 함께 설계하는 Capability Pack이다.

## 핵심 능력

- 사용자·참여자와 이해관계자 정의
- 페르소나와 실제 요구 탐색
- 사용자 여정과 접점 분석
- 불편, 이탈, 접근성 문제 발견
- 전면 경험과 후면 운영 연결
- 피드백 수집과 개선 실험

## 학습 질문

- 사용자는 어떤 상황에서 서비스를 시작하고 중단하는가?
- 사용자의 경험과 운영자의 절차가 어디에서 충돌하는가?
- 개선 효과를 어떤 행동이나 피드백으로 확인할 수 있는가?
