# Visual Communication

이미지·영상·발표자료로 메시지와 경험을 명확하게 전달하는 Capability Pack이다.

## 핵심 능력

- 대상과 핵심 메시지 정의
- Reference와 시각 기준 분석
- 콘셉트, 무드보드, 스토리보드 설계
- 이미지·영상 생성 지시 구성
- 정보 위계와 장면 흐름 설계
- 접근성, 일관성, 실제 출력 검토

## 학습 질문

- 시각물이 전달해야 할 한 가지 핵심 메시지는 무엇인가?
- Reference는 사실 근거가 아니라 방향 기준으로 사용되고 있는가?
- 사용 환경에서 글자와 행동 유도가 실제로 보이는가?
