# Knowledge Policy

## Evidence

주장의 사실성과 신뢰성을 뒷받침한다.

1. 공식 원문, 법령, 표준, 공공데이터, 공식 API
2. 동료평가 논문, 학회자료, 연구보고서
3. 검증 가능한 전문가 인터뷰, 교과서, 전문기관 자료
4. 신뢰도 높은 언론과 해설
5. 커뮤니티, SNS, 개인 블로그

낮은 단계의 자료는 탐색 신호로 사용할 수 있지만 높은 단계의 사실 증거처럼 표현하지 않는다. 출처명, 링크, 발행일 또는 확인일을 남긴다.

## Reference

결과의 방향, 톤, 구조, 시각적 기준을 제공한다. 사용자 예시, 기존 프로젝트, 브랜드 가이드, 디자인 레퍼런스 등이 해당한다. Reference를 사실 증거로 오인하지 않는다.
